Interview Explanation

I created an interactive customer segmentation dashboard using HTML, CSS and JavaScript. I used K-Means, an unsupervised machine learning algorithm, to group customers based on age, annual income and spending score. JavaScript performs the clustering, while HTML and CSS provide the dashboard interface. The results are shown through a scatter plot, cluster summaries and a customer table.

Educational project • Synthetic dataset • HTML + CSS + JavaScript
