# Customer Segmentation Dashboard

Interactive Data Science web project using HTML, CSS and JavaScript. It demonstrates K-Means clustering directly in the browser and visualizes customer groups by age, annual income and spending score.

## Features
- K selection from 2 to 5
- Change X/Y features
- K-Means clustering in JavaScript
- Scatter plot using Canvas
- Cluster summary and customer table
- Responsive UI

## Run
Keep all files together and open `index.html` in Chrome or Edge. No installation is required.

## Dataset
The dataset is synthetic educational data created for this project, not real customer information.

## Interview Answer
I created an interactive customer segmentation dashboard using HTML, CSS and JavaScript. I used K-Means, an unsupervised machine learning algorithm, to group customers based on age, annual income and spending score. JavaScript performs the clustering and Canvas displays the result. Users can change K and features and immediately see the new clusters.

## Key Questions
**Why K-Means?** It groups unlabeled data based on similarity.

**Supervised or unsupervised?** Unsupervised, because there is no target label.

**What is K?** The number of clusters to create.

**What is a centroid?** The center point of a cluster.

**Why normalize?** To stop a large-scale feature such as income from dominating distance calculations.
